# Setup-SitaraDev

This script installs all of the Texas Instruments-provided software needed to program the AM243x processor family.
It currently uses slightly outdated versions, but they can be easily updated.
They can easily be changed by swapping out the download links in the script.


## Usage

You must be connected to the internet and run this script with administrative priveleges for it to work.
It is only supported on Windows 11 24H2 or later.

```powershell
.\Setup-SitaraDev.ps1
```

Alternatively, each sub-script it invokes can be called individually.
